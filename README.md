# 🎬 App de Filmes
 
## 📖 Sobre o Projeto
 
O App de Filmes é uma aplicação mobile desenvolvida no Snack Expo utilizando React Native. O projeto permite visualizar uma lista de filmes, acessar informações detalhadas sobre cada título e proporcionar uma experiência simples e intuitiva para os usuários.
 
## 🚀 Funcionalidades
 
- Exibição de catálogo de filmes;
- Visualização de detalhes dos filmes;
- Interface amigável e responsiva;
- Navegação entre telas;
- Organização das informações de forma prática.
 
## 🛠️ Tecnologias Utilizadas
 
- React Native
- Expo Snack
- JavaScript
- CSS/StyleSheet
 
## 🎯 Objetivo
 
Desenvolver uma aplicação mobile para praticar conceitos de React Native, criação de componentes, estilização de interfaces e navegação entre telas, simulando uma plataforma de consulta de filmes.
 
## 📚 Aprendizados
 
Durante o desenvolvimento foram aplicados conhecimentos em:
 
- Desenvolvimento mobile com React Native;
- Utilização da plataforma Expo Snack;
- Estruturação de componentes;
- Gerenciamento de layout e estilos;
- Boas práticas de programação.
